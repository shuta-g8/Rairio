Rairio - data sources, attribution and modifications

1. Toei public transport data
Provider / 提供者: 東京都交通局・公共交通オープンデータ協議会
License: Creative Commons Attribution 4.0 International (CC BY 4.0) - https://creativecommons.org/licenses/by/4.0/
Train information (GTFS): https://ckan.odpt.org/dataset/train-toei
GTFS download: https://api-public.odpt.org/api/v4/files/Toei/data/Toei-Train-GTFS.zip
Station timetables: https://ckan.odpt.org/dataset/r_station_timetable-toei
Train timetables: https://ckan.odpt.org/dataset/r_train_timetable-toei
Station information and coordinates: https://ckan.odpt.org/dataset/r_station-toei
Station basics: https://catalog.data.metro.tokyo.lg.jp/dataset/t000018d0000000053
Train operations: https://ckan.odpt.org/dataset/r_train_status-toei
Train locations: https://ckan.odpt.org/dataset/r_train_location-toei
Modifications by Rairio: select the four subway lines; merge line-specific station IDs;
convert timetable and fare data; apply calendars; calculate journeys and ordinary fares;
match train observations to departures; calculate nearby stations locally from station coordinates.
Ordinary fare reference: https://www.kotsu.metro.tokyo.jp/subway/fare/regular.html

2. Kanto station and line data
API / data source: TERAREN / 駅データ.jp
API documentation: https://train.teraren.com/doc
Original database provider: 駅データ.jp / 株式会社バリューアンドビジョン
Applicable terms: https://www.ekidata.jp/agreement.php
Modifications by Rairio: select Tokyo, Kanagawa, Saitama, Chiba, Ibaraki, Tochigi and Gunma;
exclude Shinkansen and inactive stations; merge interchange station groups;
derive supplemental railway connections and independently reviewed line symbols.
This data is used under the station database terms above; it is not relicensed as CC BY.

3. Station order reference
JR East Tokyo-area route map: https://www.jreast.co.jp/map/pdf/map_tokyo.pdf
Used as a reference for Yamanote station order. The map artwork is not included.
